\subsection{Tích hợp Google Gemini AI và Chuẩn hóa Địa chỉ}

Module \code{aiService.js} đóng vai trò trung tâm trong việc nhận dữ liệu từ người dùng, đối soát với các địa điểm có sẵn trong MongoDB, xây dựng prompt và gửi tới mô hình Gemini:

\begin{lstlisting}[language=JavaScript, caption=Hàm gọi Gemini AI sinh lịch trình (aiService.js)]
const { GoogleGenerativeAI } = require('@google/generative-ai');
const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY);

async function callGeminiTravelPlanner(prompt) {
    const model = genAI.getGenerativeModel({ model: 'gemini-2.5-flash' });
    const result = await model.generateContent({
        contents: [{ role: 'user', parts: [{ text: prompt }] }],
        generationConfig: {
            responseMimeType: 'application/json',
            temperature: 0.4
        }
    });
    return JSON.parse(result.response.text());
}
\end{lstlisting}

\subsection{Hiện thực hóa Động cơ AI Autonomous Data Crawler (\code{aiCrawlerService.js})}

Động cơ \textbf{AI Data Crawler} đảm nhận vai trò tự động cào quét, bóc tách thực thể và làm giàu dữ liệu địa điểm du lịch, ẩm thực đặc sản cho 11 tỉnh thành sau sáp nhập mà không cần nhập liệu thủ công:

\begin{lstlisting}[language=JavaScript, caption=Động cơ cào dữ liệu tự động bằng Gemini AI (aiCrawlerService.js)]
// Thu thập 15-25 địa điểm đa danh mục cho mỗi tỉnh thành sau sáp nhập
async function crawlPlacesByAI(destination) {
  const geminiKey = getGeminiKey();
  let placesToSave = [];
  const contextHint = LOCAL_CONTEXT_PROMPT_MAP[destination];

  // Kỹ thuật Retry with Exponential Backoff đảm bảo độ tin cậy
  for (let attempt = 1; attempt <= 3; attempt++) {
    try {
      const prompt = `Bạn là AI Data Web Crawler Du lịch & Ẩm thực Việt Nam.
Hãy cào quét và trích xuất 15 đến 25 địa điểm du lịch, đặc sản tại "${destination}" 
(Bao gồm khu vực mở rộng sau sáp nhập: ${contextHint}).
Đủ 4 nhóm: "attraction", "restaurant", "cafe", "hotel".
Mỗi địa điểm có: name, address cụ thể, description, tags, estimated_cost, GPS.
Trả về JSON array thuần túy.`;

      const res = await axios.post(
        `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${geminiKey}`,
        { contents: [{ parts: [{ text: prompt }] }] }
      );
      const raw = res.data.candidates?.[0]?.content?.parts?.[0]?.text;
      placesToSave = parseAndCleanJSON(raw);
      if (placesToSave.length > 0) break;
    } catch (err) {
      if (attempt < 3) await sleep(2500 * attempt);
    }
  }

  // Tự động gán ảnh HD Unsplash và Atomic Upsert vào MongoDB
  for (const place of placesToSave) {
    place.image = resolveHDPhoto(destination, place.type);
    await Place.updateOne(
      { name: place.name, destination: place.destination || destination },
      { $set: place },
      { upsert: true }
    );
  }
  return placesToSave;
}
\end{lstlisting}

\subsection{Cơ chế Tự Động Kích Hoạt Ngầm (\en{Background Ingestion \& On-Demand})}

Hệ thống triển khai cơ chế kích hoạt 2 tầng hoàn toàn tự động và trong suốt:
\begin{enumerate}
    \item \textbf{Khởi động máy chủ (\en{Server Boot Ingestion}):} Khi máy chủ Node.js khởi động trong \code{server.js}, hàm \code{autoInitPlaces()} sẽ duyệt qua 11 tỉnh thành. Nếu phát hiện tỉnh thành nào có số lượng bản ghi $< 15$, hệ thống sẽ tự động kích hoạt tác vụ cào ngầm để nạp đủ dữ liệu.
    \item \textbf{Truy vấn động (\en{On-Demand Fallback}):} Khi người dùng gửi yêu cầu \code{GET /api/places?destination=...}, nếu cơ sở dữ liệu có ít hơn 10 địa điểm, API sẽ tự động kích hoạt \code{crawlPlacesByAI(destination)} ngay trong luồng xử lý trước khi trả về kết quả cho Frontend.
\end{enumerate}

\section{Hiện thực hóa Frontend App-First với Vue.js 3}

Giao diện người dùng được tổ chức theo kiến trúc 5 Tab linh hoạt trong file \code{frontend/src/App.vue}:

\begin{enumerate}
    \item \textbf{Tab Khám phá (\code{activeTab === 'explore'}):} Trình bày danh sách các thành phố Miền Trung dạng thẻ ảnh trượt ngang (\en{Hero Carousel}), kèm widget dự báo thời tiết trực tiếp từ \en{Open-Meteo} và danh sách lưới địa điểm có ảnh thực tế độ nét cao, nhãn phân loại màu sắc và nút bấm \code{+ Lên lịch trình}.
    \item \textbf{Tab Lên lịch (\code{activeTab === 'planner'}):} Form chọn số ngày (1--7 ngày), thanh trượt ngân sách, nút chọn nhanh địa danh và dòng thời gian (\en{Timeline}) hiển thị từng mốc hoạt động kèm nút \code{🗺️ Chỉ đường} mở Google Maps.
    \item \textbf{Tab Chuyến đi (\code{activeTab === 'saved'}):} Quản lý lịch sử các chuyến đi đã tạo, hỗ trợ xem lại, xóa hoặc chia sẻ.
    \item \textbf{Tab Trợ lý AI (\code{activeTab === 'ai'}):} Khung chat tư vấn du lịch thời gian thực theo phong cách ứng dụng tin nhắn hiện đại.
    \item \textbf{Tab Tài khoản (\code{activeTab === 'profile'}):} Quản lý thông tin tài khoản, danh sách địa điểm yêu thích và form đăng nhập/đăng ký.
\end{enumerate}

\section{Hiện thực hóa Tiện ích Nâng cao}

\subsection{Công cụ Chia tiền Nhóm (Group Bill Splitter)}
Module cho phép người dùng thêm các mục chi tiêu (tiền khách sạn, ăn uống, vé tham quan, xăng xe), tự động tính tổng chi phí và chia đều cho từng thành viên:
$$\text{Chi phí mỗi người} = \frac{\sum \text{Khoản chi}}{\text{Số lượng thành viên}}$$

\subsection{Đổi lịch Tránh mưa Thông minh (Weather Smart Re-scheduler)}
Khi người dùng kích hoạt tính năng tránh mưa, hệ thống duyệt qua mảng hoạt động trong ngày và tự động thay thế các địa điểm ngoài trời (\en{beach}, \en{mountain}) bằng các điểm trong nhà (\en{museum}, \en{indoor cafe}, \en{culinary hall}) mà vẫn bảo toàn quỹ thời gian và chi phí.
