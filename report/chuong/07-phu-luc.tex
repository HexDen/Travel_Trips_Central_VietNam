\section*{A. Hướng dẫn Cài đặt \& Chạy Mã nguồn}

\subsection*{1. Yêu cầu Môi trường}
\begin{itemize}
    \item \en{Node.js} phiên bản $\ge 18.0.0$.
    \item \en{MongoDB Atlas URI} hợp lệ và kết nối Internet để gọi \en{Gemini AI API}.
    \item \en{Google Gemini API Key} cấu hình trong file \code{backend/.env}.
\end{itemize}

\subsection*{2. Cấu hình Biến Môi trường Backend}
Tạo file \code{backend/.env} với nội dung:
\begin{lstlisting}[language=bash]
PORT=3000
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/travel_trips
GEMINI_API_KEY=AIzaSy...
JWT_SECRET=TravelTripsSecretKey2026
\end{lstlisting}

\subsection*{3. Khởi chạy Hệ thống}
\begin{lstlisting}[language=bash]
# Terminal 1 - Backend Server
cd backend
npm install
npm start
# Server khoi chay tai http://localhost:3000

# Terminal 2 - Frontend App
cd frontend
npm install
npm run dev
# Ung dung khoi chay tai http://localhost:5173
\end{lstlisting}
